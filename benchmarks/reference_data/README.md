# Reference-data provenance and reuse notice

This directory contains numerical coordinates used for comparisons with
published calculations or independently supplied simulation data.  Each
dataset records its source, units, extraction history when known, file
checksums, and publication or provider attribution.

These values are reference data, not Otter source code.  Except where a
dataset declares a specific open license, its license status is
`NOASSERTION`; Otter's BSD-3-Clause software license does not grant rights in
those values.  Consult the cited source and dataset manifest before reuse or
redistribution.

Source PDFs are not included.  Otter-generated calculation results are kept
separately under `benchmarks/baselines/`.
