# Reference-data provenance and reuse notice

This tree contains compact numerical coordinates used to compare Otter with
published calculations or independently supplied simulation data.  Every
dataset has a local `README.md` and a local or explicitly linked
machine-readable manifest that identifies its source, physical units,
extraction history, file checksums, and publication or provider attribution.

These files are reference data, not Otter source code.  Except where a local
manifest records a specific open license (currently the Bethkenhagen *et al.*
CC BY 4.0 material), the declared data-license status is `NOASSERTION`.
Consequently the repository's BSD-3-Clause software license does **not** grant
rights in those third-party-derived or author-provided numerical values.

On 2026-08-10 the Otter project maintainer made an explicit repository policy
decision to publish the listed reference files with detailed source
attribution.  This decision is recorded as
`published_by_maintainer_with_attribution` in each affected manifest.  It is
not a claim that a publisher or data provider supplied an open-data license.
Downstream users remain responsible for consulting the cited source and the
dataset manifest before reuse or redistribution.

Source PDFs are not included.  Otter-generated numerical baselines are kept
separately under `benchmarks/baselines/` and are identified as project output.
