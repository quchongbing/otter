# Starrett–Saumon single-species reference curves

These eight headerless, two-column curves are local numerical extractions
from C. E. Starrett and D. Saumon, *High Energy Density Physics* **10**,
35–42 (2014), DOI
[10.1016/j.hedp.2013.12.001](https://doi.org/10.1016/j.hedp.2013.12.001),
PII `S1574181813001900`.

Column 2 is the dimensionless ion pair distribution \(g_{ii}(r)\).
The first-column unit is recorded per file in `manifest.json`; conversion to
\(r/R_{\rm WS}\) is performed only while plotting. Small negative values are
retained as extraction noise. The local files do not encode an unambiguous
method label for every curve, so none is invented.

The source publication and its PDF are not bundled.  The maintainer has
explicitly chosen to publish the numerical extractions with source
attribution and license status `NOASSERTION`; they are not covered by
Otter's BSD-3-Clause software license.  This repository policy does not
assert a publisher- or author-supplied data license.  See `manifest.json` and
the parent reference-data notice before reuse.
