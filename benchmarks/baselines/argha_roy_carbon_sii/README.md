# Current Otter states for the Argha Roy DFT-MD comparison

These five archives were generated by the complete gallery program
`benchmarks/examples/plot_argha_roy_carbon_sii.py`. They contain only
current-Otter average-atom, pseudoatom, QOZ, and HNC results and are separate
from the author-provided DFT-MD reference package.

The accepted temperature grid is 20, 30, 40, 50, and 100 eV at
`rho = 3.51538 g/cc`. Every state passes the full-AA stage-2, external-AA,
threshold-state, HNC fixed-point, and real/reciprocal transform-closure
checks. The 20--50 eV shallow states are resolved by analytic negative-energy
exterior matching on the physical AA box; no artificial extended bound-only
box is used.

With `USE_PRECOMPUTED_DATA = True`, the gallery verifies the checksums in
`manifest.json` and loads these reviewed results. With the switch set to
`False`, the same standalone gallery file recalculates all five states and
writes candidates under
`benchmarks/outputs/argha_roy_carbon_sii/gallery_recomputed`.

The DFT-MD files were provided by Dr. Argha Roy (private communication;
unpublished).  They are published by maintainer decision with attribution
and license status `NOASSERTION`; see the separate reference manifest and
reference-data notice.  The Otter baselines themselves are project-generated
outputs.
