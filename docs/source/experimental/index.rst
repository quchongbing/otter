Experimental models
===================

Experimental modules are available for controlled research comparisons, but
their algorithms, output contracts, and defaults may change without the
stability guarantees of the main IS workflow.

.. warning::

   Experimental completion is not production validation.  Preserve the
   reference IS result, enable strict convergence checks, and report the full
   iteration history whenever experimental output is used.
