Example gallery
===============

Self-contained examples cover average-atom electronic structure, QM/TF and
IS/SC comparisons, one- and multicomponent QOZ/HNC, LFC sensitivity,
ionization and pressure ionization, and continuum-resonance diagnostics.

Each page places figures and terminal diagnostics before its complete,
downloadable Python source.  The input block selects either checksummed
Otter results or a fresh calculation; every figure is exported as PNG and
vector PDF.  Published-data comparisons live in the separate
:doc:`scientific benchmark gallery </benchmarks/gen_benchmarks/index>`.
